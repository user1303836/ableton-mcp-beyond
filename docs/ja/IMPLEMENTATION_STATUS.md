## エビデンスの境界

[`../evidence/`](../evidence/) の下の追跡されたエビデンスは、決定論的
fake-Live、パッケージブリッジ、実 Live 観測を区別します。Phase 8 実 Live
エビデンスは、インストールされた `npm pack` 成果物によって macOS Live
12.4.5b8 に対して生成され、キャンセルとホスト再起動/ウォッチドッグ回復を
含みます。Windows Live の証明ではなく、署名/公証やリリース公開を証明する
ものでもありません。

ローカルの保護された `extensions-sdk-1.0.0-beta.0` は除外されたままです:
開く、コピー、ステージ、パッケージ、実装エビデンスとして引用してはいけません。

## 正直な制限

- デバイスと Arrangement クリップの恣意削除は、以前の状態を再構成できない
  ため拒否されます。ガード付きアンドゥによる、正確なトランザクション作成 ID、
  階層、作成フィンガープリントのクリーンアップのみが利用可能です。
- Live の保存/開く/新規/エクスポート/収集/バウンス、Arrangement オートメー
  ション、ワープマーカー編集、テイク/コンプ編集、Browser オーディオプレビューは、
  観測された API に権威ある操作がない場合は利用不可のままです。厳密な予約済み
  正規契約はテストされていますが、アダプターが実行および検証できるまで通知
  されません。
- Max for Live `.amxd`、プラグイン UI コントロール、ストリーミング PCM タップ、
  任意パス/URL 解析、イマーシブ/オブジェクトラウドネスレイアウト、自動マス
  タリング判定、フォレンジック安全消去は主張されません。
- トゥルーピークは現在 44.1 kHz と 48 kHz で検証されています。その他のレートは
  利用不可と報告します。
- Live キャプチャには、保存された Set、WAV 録音、選択可能で復元可能な
  デスティネーションルート、明示的な同意/出力安全性、実 Live 出所が必要です。
- 現在追跡されている実 Live 証明は macOS 上であり、候補固有のままです。ホスト
  されたホスト/パッケージエビデンスは、完全な正確な SHA マトリクスがグリーンの
  場合にのみ有効です。過去の実行が新しいコミットに移管されることはありません。
  パフォーマンスは V8 カバレッジとは別のインスツルメントされていないゲートの
  ままです。
- stdio ジャーニーサーフェスはテキストファーストで、サーバー所有の視覚的
  フォーカスはありませんが、サードパーティ MCP クライアント、Ableton Live、
  プラグインウィンドウでの VoiceOver/Narrator の動作はクライアント/バージョン
  依存であり、主張されません。
- ネイティブ署名/公証、Windows デスクトップ/実 Live エビデンス、外部
  VoiceOver/Narrator/クライアントエビデンス、公開配布は現在のチャネルでは
  利用できません。チャネルはローカル・未署名・未公証・未公開で、
  `private: true` は誤公開を防ぐだけで MIT の権利を変更しません。これらのセルは
  ホスト CI またはサーバー所有のテキストアクセシビリティ契約から推測されません。
