# サポートおよびエビデンスプラットフォームマトリクス

[English](../en/SUPPORT_MATRIX.md) · [简体中文](../zh-CN/SUPPORT_MATRIX.md) · 日本語

「サポート」は、ホスト/パッケージサポートと実際の Ableton Live 認証に
分かれています。グリーンのホストセルが Live セルに昇格することはありません。

## ランタイムとオペレーティングシステム

| サーフェス | バージョン / アーキテクチャ | ステータス | エビデンス |
|---|---|---|---|
| Node.js | 22.x、24.x、25.x | 正確な SHA マトリクスがグリーンの候補に対するサポートされたホスト/パッケージ契約のみ | [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml);別の SHA の設定または結果はエビデンスではありません |
| Node.js | 26.x または将来のメジャー | サポートされていないリリースランタイム | 明示的なマトリクスとエンジン範囲の更新が必要です |
| macOS ホスト | GitHub `macos-15`;ローカル macOS arm64 環境 | 正確な SHA ジョブがパスした場合のみホスト/パッケージ契約をサポート | Node/パッケージ/ライフサイクルゲート。別途ローカル Live エビデンスが必要です |
| Windows ホスト | GitHub Windows Server 2025 x64(`windows-2025`) | 正確な SHA ジョブがパスした場合のみホスト/パッケージ契約をサポート | Node/パッケージ/ライフサイクル/ACL/ジャンクション/保持ファイルゲート。Windows 11 や Live のエビデンスではありません |
| Windows デスクトップ | Windows 11 x64 | 手順は文書化済み、未認証 | 正確な候補ホストと Live エビデンスが必要。Server ステータスを継承してはいけません |
| Linux ホスト | Ubuntu 24.04 x64(`ubuntu-24.04`) | ホスト契約のみサポート | Node/パッケージゲート。Live の主張なし |

パッケージエンジン範囲は `>=22 <26` です。正確なリリースは Node 22、24、
25 のいずれかを使用できます。OS ベンダーのライフサイクル変更は、暗黙の
サポートではなくマトリクスの更新を必要とします。

## Ableton Live

| OS | Live バージョン / エディション | ステータス | エビデンス / 制限 |
|---|---|---|---|
| macOS | Live 12.4.5b8 ベータ。インストールされたエディションは Remote Script ステータス API では公開されません | 観測されたエンジニアリングターゲットであり、公開リリース認証ではありません | [`../evidence/`](../evidence/)。最終候補ダイジェストで再実行する必要があります。エディションは明示的に不明のままです |
| macOS | Live 12 Suite | ネゴシエート契約。エディション固有の認証なし | 共通 API は実行時に発見されます。Suite デバイス/コンテンツは想定されません |
| macOS | Live 12 Standard | ネゴシエート契約。エディション固有の認証なし | 欠落しているデバイス/コンテンツは利用不可のままです |
| macOS | Live 12 Intro | ネゴシエート契約。エディション固有の認証なし | 削減された機能/コンテンツサーフェスは利用不可のままです |
| Windows 11 | Live 12 Suite / Standard / Intro | 未認証 / 外部環境利用不可 | サーバーホスト CI は Windows Live ではありません。各エディションにはインストール、アクティベーション、変更、再起動、回復、アンインストールのエビデンスが必要です |
| Linux | 任意 | 非対応 | この製品は Linux 向けに Ableton Live を提供しません |
| Live 11 以前 | 任意 | 非対応/未検証 | プロトコル/API 互換性は主張されません |

## アクセシビリティ

サーバー所有の stdio テキスト契約は、セマンティックな順序、プレーンテキスト、
非カラーステータス、ポインター非依存についてテストされています。VoiceOver、
Narrator、Ableton Live、プラグインウィンドウ、ターミナル、サードパーティ MCP
クライアントは、バージョン依存の外部サーフェスであり、サーバーテストでは
認証されていません。

## リリースの影響

パッケージされた tarball は署名なしでビルドおよびライフサイクルテストが
可能です。候補は、すべての正確な SHA CI マトリクスジョブがパスした場合にのみ
ホストリリース準備が整います。Windows Server ホストエビデンスは、Windows 11、
Ableton Live、Narrator、プラグインウィンドウを認証しません。これらの外部セルは、
適切な環境が候補に紐づくエビデンスを生成するまで明示的に利用不可のままであり、
パスしたセルとして書き換えてはいけません。
